# 🚲 Bike Sales Analysis (India)

## 📌 Overview

This project performs Exploratory Data Analysis (EDA) on a bike dataset to understand trends in brand distribution, fuel types, pricing, and geographic patterns.

## 📊 Key Insights

* Brand distribution is relatively balanced with no strong dominance
* Petrol bikes dominate the dataset
* Price and resale value show positive correlation
* Registration trends increase over years (dataset-based trend)

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn
